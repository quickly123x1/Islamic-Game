# Islamic Challenge — إصلاحات النسخة الحالية

هذه الحزمة مبنية على ملفات موقعك الحالي، وليست إعادة تصميم أو مشروعًا جديدًا.

## الملفات التي تُستبدل في GitHub
- `index.html`
- `style.css`
- `script.js`
- `online.js`
- `supabase-config.js` (مرفق كما هو من ملفاتك الحالية)

## الإصلاحات المنفذة
1. إصلاح خطأ `windowwindow.onlineSyncState` الذي كان يمنع مزامنة تقدم الحساب.
2. جعل المزامنة تتعامل مع أخطاء الاتصال وتعيد حالة المزامنة إلى وضعها الطبيعي.
3. تهيئة بيانات الحفظ القديمة عند تحميلها حتى لا تتعطل الصفحات إذا كانت بعض الحقول غير موجودة.
4. حفظ إجابة السؤال الحالي واستعادتها بعد تحديث الصفحة، ومنع احتساب الإجابة نفسها مرتين بسبب إعادة التحميل.
5. إصلاح التقدم عند السؤال الأخير حتى لا تضيع نتيجة المستوى إذا أُغلقت الصفحة قبل الضغط على زر النتيجة.
6. منع تكرار مكافأة إنهاء المستوى عند الضغط المتكرر.
7. منع فتح صفحات الملف الشخصي والمنافسات قبل بدء اللعب أو تسجيل الدخول.
8. توحيد وصف المجموعة الخاصة مع حد الأعضاء الذي يستخدمه الكود (حتى 20 صديقًا بالإضافة إلى المنشئ).

## طريقة التحديث الآمنة
1. احتفظ بنسخة احتياطية من ملفات GitHub الحالية قبل الاستبدال.
2. ارفع الملفات الخمسة أعلاه إلى جذر المستودع نفسه، مع الإبقاء على أسماء الملفات كما هي.
3. لا تغيّر إعدادات Supabase ولا تشغّل ملف SQL المرفق سابقًا مرة أخرى ضمن هذا التحديث؛ هذه الحزمة لا تحتاج ترقية قاعدة بيانات.
4. بعد الرفع، افتح الموقع وحدّث الصفحة تحديثًا كاملًا، ثم اختبر اللعب كضيف وتسجيل الدخول.

## ملاحظات
- لم تُحذف أي بيانات من قاعدة البيانات ولم يتضمن هذا التحديث أوامر SQL.
- تم الإبقاء على إعداد Supabase الحالي كما ورد في ملفاتك. لا تضع أبدًا مفتاح `service_role` أو أي مفتاح سري داخل ملفات الموقع.
- فُحصت صياغة ملفات JavaScript باستخدام `node --check`. يلزم اختبار الاتصال الفعلي بحسابك في الموقع بعد النشر؛ لا يمكن تأكيده دون تنفيذ تسجيل دخول حقيقي.
