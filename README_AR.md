# Islamic Challenge — النسخة المهيأة للأونلاين

## ما الذي يعمل الآن؟
- اللعبة الأصلية: 3 مستويات و45 سؤالًا، متجر، مهام يومية، إنجازات، ملف شخصي ومقتنيات.
- حفظ الضيف محليًا على الجهاز والمتصفح.
- واجهة إنشاء حساب وتسجيل دخول بالبريد وكلمة المرور عبر Supabase.
- مزامنة حالة اللعبة إلى حساب اللاعب بعد إعداد Supabase.
- لوحة متصدرين عالمية لأفضل 50 لاعبًا.

## 1) إعداد قاعدة البيانات
1. افتح مشروعك في Supabase.
2. افتح **SQL Editor** ثم **New query**.
3. افتح ملف `supabase-schema.sql` وانسخ محتواه إلى المحرر.
4. اضغط **Run**.

## 2) إضافة بيانات الاتصال
1. في Supabase افتح **Project Settings → API Keys**.
2. انسخ **Project URL**.
3. انسخ **Publishable key** (أو المفتاح العام `anon` القديم إن كانت لوحة مشروعك تعرضه).
4. افتح `supabase-config.js` وضع القيم مكان `YOUR_SUPABASE_PROJECT_URL` و`YOUR_SUPABASE_PUBLISHABLE_KEY`.

مثال شكلي فقط:
```js
window.SUPABASE_CONFIG = {
  url: "https://YOUR-PROJECT.supabase.co",
  publishableKey: "YOUR_PUBLIC_PUBLISHABLE_KEY"
};
```
لا تضع أبدًا `service_role` أو `secret key` أو كلمة مرور قاعدة البيانات في ملفات الموقع أو ترسلها لأحد.

## 3) إعداد تأكيد البريد
من Supabase افتح **Authentication → URL Configuration** واضبط Site URL بعد نشر الموقع. أثناء الاختبار المحلي يمكن تعطيل تأكيد البريد مؤقتًا من إعدادات Email فقط إذا رغبت، والأفضل إبقاؤه مفعّلًا.

## 4) تجربة محلية
افتح `index.html` عبر خادم محلي أو معاينة Acode. بعض إعدادات المصادقة وإعادة التوجيه تعمل بصورة أفضل عبر رابط HTTPS بعد النشر، وليس عند فتح الملف مباشرة بصيغة `file://`.

## 5) النشر لاحقًا
ارفع مجلد المشروع إلى GitHub ثم اربطه بـ Vercel أو Netlify. اجعل رابط النشر هو Site URL في إعدادات Supabase.

## ملاحظات مهمة
- لا ترفع `supabase-config.js` إذا كان يحتوي أي مفتاح سري؛ المفتاح Publishable/anon وحده مناسب للواجهة مع سياسات RLS.
- هذه النسخة تتيح لوحة متصدرين عالمية أساسية. لا يوجد حتى الآن تحدٍّ مباشر لحظي بين لاعبين، أو ترتيب أسبوعي/شهري منفصل.
- حماية RLS تمنع المستخدم من تعديل صف لاعب آخر، لكن حفظ النقاط من جهة المتصفح ليس نظامًا مقاومًا للغش بالكامل. قبل إطلاق منافسات بجوائز أو ترتيب تنافسي عالي الأهمية، ينبغي نقل احتساب النقاط والتحقق من الإجابات إلى وظائف خادمية.
- حساب الضيف يبقى محليًا؛ عند إنشاء حساب جديد، إذا لم توجد بيانات سحابية فسيتم رفع تقدم الجهاز الحالي للحساب.
